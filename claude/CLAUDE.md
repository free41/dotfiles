# Global Claude Code Instructions

This file provides global guidance to Claude Code across all projects.

## General Preferences

- Code style: Follow existing conventions in each project
- Documentation: Prioritize clear, concise comments
- Testing: Write tests for new features when applicable
- Git: Use conventional commit message style

## Common Patterns

- Python: Use type hints, follow PEP 8
- Shell scripts: Use bash, include error handling with `set -euo pipefail`
- Configuration: Use YAML/TOML for config files when possible

## Workflow Preferences

- Always review changes before committing
- Run tests before pushing
- Keep commits focused and atomic
